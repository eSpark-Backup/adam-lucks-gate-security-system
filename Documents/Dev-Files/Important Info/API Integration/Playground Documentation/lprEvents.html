LPR (License Plate Recognition) Events

Introduction

LPR events are used for detecting the license plate. There are four events involved during the life cycle of license plate detection.

Event Triggered when
DEVICE_LPR_PLATE_FOUND License plate is detected initially by the LPR system
DEVICE_LPR_PLATE_UPDATE Detected license plate is updated
DEVICE_LPR_PLATE_LOST License plate no longer detected in the region of interest
DEVICE_LPR_MATCH License plate in an LPR watch list was detected

Interpret ROI to construct the cropped Image from Actual image

Region of Interest (ROI) information is shared in DEVICE_LPR_PLATE_FOUND, DEVICE_LPR_PLATE_LOST and DEVICE_LPR_MATCH events.

DEVICE_LPR_PLATE_FOUND and DEVICE_LPR_PLATE_LOST

top left x = (roi.topLeft.x * image.PixelWidth) 
top left y = (roi.topLeft.y * image.PixelHeight) 
width = (roi.bottomRight.x * image.PixelWidth - roi.topLeft.x * image.PixelWidth)
height = (roi.bottomRight.y * image.PixelHeight - roi.topLeft.y * image.PixelHeight)

crop = width:height:x:y

DEVICE_LPR_MATCH

top left x = (plateBox.left * image.PixelWidth)
top left y = (plateBox.top * image.PixelHeight)
width = (plateBox.right * image.PixelWidth - plateBox.left * image.PixelWidth)
height = (plateBox.bottom * image.PixelHeight - plateBox.top * image.PixelHeight) 

crop = width:height:x:y
